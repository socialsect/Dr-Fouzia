# Design Brief — Dr. Fouzia Al Ali Website

```
Purpose:    Premium medical practice website for a consultant family physician
Audience:   Health-conscious adults in Dubai, researching functional medicine on mobile/desktop
Tone:       Warm Editorial — magazine feature spread meets clinical credibility
Reference:  Monocle magazine, Kinfolk journal, Aesop storefronts
Palette:    Sky-blue base (#E1F2FD), brand-blue accent (#2F91BC), deep ink (#0E2A3A), white surfaces
Type:       DM Serif Display (editorial headlines) + Inter (clean body/UI) — serif authority, sans readability
Memorable:  The full-screen navigation that opens like an editorial canvas
Restraint:  No purple gradients, no glassmorphism, no floating blobs, no card grids for everything
```
